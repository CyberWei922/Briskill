# LocalAssistant

LocalAssistant 是一个原生 macOS 菜单栏 AI 助手原型。当前版本已经从纯 UI Demo 进入可交互的核心功能原型。

## 版本状态

当前版本：**1.3 Beta**

这是一个早期开发版本。目前已经可以体验的核心链路是：

```text
配置 DeepSeek 或 Gemini API
→ 通过四步引导或自由模式描述一个个人技能
→ 模型生成结构化技能草稿
→ 预览并保存到本地
→ 在快捷面板中搜索技能并收集文本、文件或图片等参数
→ 在设置中编辑、停用、删除或导出技能
```

OCR、剪贴板读取与历史、本地文件操作、选中文字处理、系统诊断、Spotlight 集成、本地模型，以及保存后技能的完整工具执行能力均仍在开发中。文件和图片参数目前完成的是接收、校验与绑定，还没有接入 OCR 或多模态模型执行。GLM 和 OpenAI 已有初步接口代码，但本 Beta 版本的透明流式技能生成暂不视为可用功能。

完整的产品方向、功能范围和长期约束记录在 [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md)。后续开发应先阅读该文档。

当前已经完成的基础框架：

- 菜单栏入口
- `Option + Space` 全局快捷键
- 带命令预测和最近技能的快捷操作主面板
- DeepSeek 与 Gemini 的透明流式技能生成调用
- 智谱 GLM、OpenAI 的实验性统一接口
- macOS Keychain API Key 存储和连接测试
- 普通问题的云端模型调用原型
- “引导模式 / 自由模式”自定义技能创建器
- AI 生成结构化技能草稿、执行计划和权限说明
- 自定义技能的本地持久化和搜索匹配
- 技能创建前区分“本地执行”和“云端 AI”；本地执行允许使用经过授权的网络能力，但禁止调用云端模型
- 云端技能通过统一的 `model.generateText` 保存运行时提示词模板，不绑定具体服务商
- 快捷面板支持灰色内联补全、`Tab`/方向键循环候选以及回车执行当前候选
- 文本、文件、图片、文件夹、数字和布尔值技能参数定义
- Finder 拖拽、剪贴板粘贴和原生文件选择器参数输入
- 类 Xcode 的 Liquid Glass 设置界面和滚动感知标题分隔线
- 技能搜索、编辑、启停、删除和版本化 `.laskill` 导出
- 主面板、生成过程和历史记录的安全 Markdown 渲染
- 更宽容的递归 JSON 参数解析和可定位字段的生成错误信息

尚未接入的系统执行能力包括选中文字读取、Apple Vision OCR、文件操作、剪贴板历史和系统诊断。它们当前仍显示功能雏形或缺失能力，不会伪装成已经执行成功。

## 打开工程

使用 Xcode 打开 `LocalAssistant.xcodeproj`，选择 `LocalAssistant` scheme 后运行。

版本变更记录见 [`CHANGELOG.md`](CHANGELOG.md)。
