# Briskill

Briskill 是一款原生 macOS 菜单栏自动化助手：用一个索引调用本地工具、云端模型或两者组合的可编辑技能。

## 版本状态

当前开发版本：**2.1 Beta**（2.0 已作为改名前基线发布）

这是一个早期开发版本。目前已经可以体验的核心链路是：

```text
配置 DeepSeek 或 Gemini API
→ 通过四步引导或自由模式描述一个个人技能
→ 模型生成结构化技能草稿
→ 预览并保存到本地
→ 使用“索引 参数1 参数2 … 条件”在快捷面板调用技能
→ 在设置中编辑、停用、删除或导出技能
```

2.x 已经接入剪贴板读写与历史、直接文字参数、Apple Vision OCR、屏幕区域截图、文件读取/列表/搜索/重命名/废纸篓、AppleScript 和系统诊断快照，并统一接入 Skill Runtime V3。设置中可以管理辅助功能、屏幕录制和文件夹访问权限；API Key 默认保存在钥匙串，也可以由用户主动迁移到可查看的本地文件。

完整的产品方向、功能范围和长期约束记录在 [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md)。后续开发应先阅读该文档。

当前已经完成的基础框架：

- 菜单栏入口
- `Option + Space` 全局快捷键
- 带命令预测和最近技能的快捷操作主面板
- DeepSeek 与 Gemini 的透明流式技能生成调用
- 智谱 GLM、OpenAI 的实验性统一接口
- macOS Keychain API Key 存储和连接测试
- 普通问题的云端模型调用原型
- “引导模式 / 自由模式”自定义技能创建器
- AI 生成结构化技能草稿、执行计划和权限说明
- 自定义技能的本地持久化和搜索匹配
- 技能创建前区分“本地执行”和“云端 AI”；本地执行允许使用经过授权的网络能力，但禁止调用云端模型
- 云端技能通过统一的 `model.generateText` 保存运行时提示词模板，不绑定具体服务商
- 快捷面板支持灰色内联补全、`Tab`/方向键循环候选以及回车执行当前候选
- 文本、文件、图片、文件夹、数字和布尔值技能参数定义
- Finder 拖拽、剪贴板粘贴和原生文件选择器参数输入
- 类 Xcode 的 Liquid Glass 设置界面和滚动感知标题分隔线
- 技能搜索、编辑、启停、删除和版本化 `.bsk` 导出
- 简体中文、英文和跟随系统的应用语言选择，切换后重启生效
- 主面板、生成过程和历史记录的安全 Markdown 渲染
- 更宽容的递归 JSON 参数解析和可定位字段的生成错误信息
- 首个真实本地工具闭环：读取剪贴板 → 云端模型处理 → 显示并写回剪贴板
- 最小 Tool Registry、顺序 Workflow Engine、逐步脱敏日志和旧版剪贴板技能兼容
- 14 个使用标准 Skill Definition 保存的默认技能，覆盖 OCR、直接文字处理、剪贴板、文件和卡顿诊断
- 默认技能只额外标记为“内置技能”，仍可编辑、停用、导出或删除；删除状态会持久化，不会在下次启动时强制恢复
- 修改文件和移到废纸篓前使用原生确认框
- 本地调用历史记录问答/技能的输入、结果、状态、耗时和真实工具链，可在设置中查看、搜索、单条删除或全部清空
- 通用设置提供系统/浅色/深色外观、六种预设主题色和“跟随系统强调色”，悬浮窗会即时跟随
- 真实权限中心可申请和管理辅助功能、屏幕录制以及用户选择的文件夹访问范围
- API Key 支持在 macOS 钥匙串与可查看的本地文件之间安全迁移，默认使用钥匙串
- `ask` 连续对话、滚动上下文压缩、会话级历史恢复和真实 Token 用量记录
- 完全本地的剪贴板历史：文本、Finder 文件和图片记录，快捷面板搜索与键盘选择，活动记录与可选加密完整归档
- 可配置的主面板与剪贴板全局快捷键，以及状态栏、Dock 图标的打开动作
- GitHub Releases 手动/每日更新检查、关于页面和登录时自动启动
- DeepSeek 模型与余额读取，以及四个云端服务商的独立连接配置

尚未接入的主要能力包括剪贴板语义搜索与收藏固定、通用网络请求、通知、Spotlight App Intents/Core Spotlight 动态技能、本地小模型、技能包导入和技能版本历史。未注册的能力会明确显示缺失工具，不会伪装成已经执行成功。

当前仓库发布的是 macOS 版本。Windows 原生客户端仍处于独立开发和真实 Windows 11 验证阶段，不包含在本次代码提交中。

## 打开工程

使用 Xcode 打开 `Briskill.xcodeproj`，选择 `Briskill` scheme 后运行。

版本变更记录见 [`CHANGELOG.md`](CHANGELOG.md)。
