# Briskill

**用一句指令，在 Mac 上完成翻译、OCR、文件处理、剪贴板操作和个人自动化。**

Briskill 是一款原生 macOS 智能工具。按下快捷键，输入你想做的事，它会调用本地工具、你选择的 AI 服务，或把两者组合成可以重复使用的个人技能。

> [!IMPORTANT]
> Briskill 目前处于 **2.1 Beta** 开发阶段，尚未提供可直接下载安装的正式版本。当前仓库提供 macOS 源码，适合体验、测试和参与开发。

## Briskill 能做什么

### 快速处理日常任务

- 翻译、解释和改写文字
- 对屏幕区域或图片进行本地 OCR
- 读取、搜索、总结和重命名文件
- 在下载目录快速创建空文件
- 查看文件夹内容或将文件移到废纸篓
- 读取系统状态并解释电脑卡顿的可能原因
- 直接向已配置的 AI 服务提问，并继续多轮对话

### 找回复制过的内容

按 <kbd>⌘</kbd> + <kbd>⌥</kbd> + <kbd>V</kbd> 打开剪贴板历史：

- 保存文字、Finder 文件和图片
- 输入关键词快速搜索
- 使用方向键、回车或 <kbd>⌘</kbd> + <kbd>1…9</kbd> 快速选择
- 将历史内容设为当前剪贴板，或直接粘贴回之前的应用
- 自定义记录数量、保留时长、面板大小和显示位置
- 可选启用加密完整归档，并使用 Touch ID 或 Mac 密码保护访问

### 创建自己的技能

你可以直接描述一个希望重复使用的流程，例如：

> 以后我输入“会议收尾”并粘贴会议记录，就把内容整理成按优先级排序的待办清单。

Briskill 会生成结构化技能草稿，展示执行步骤、需要的输入、使用的工具、权限和数据去向。确认保存后，技能会立即出现在快捷面板中，并且可以继续编辑、停用、导出或删除。

## 如何使用

按 <kbd>⌥</kbd> + <kbd>Space</kbd> 打开主面板，然后输入命令或问题。

| 输入示例 | 作用 | 执行位置 |
|---|---|---|
| `ocr` | 框选屏幕区域并识别文字 | 完全本地 |
| `ocrfile` + 图片 | 识别图片中的文字 | 完全本地 |
| `trans 这是一段需要翻译的文字` | 翻译直接输入的内容 | 云端 AI |
| `cliptrans` | 翻译当前剪贴板并写回 | 本地 + 云端 AI |
| `read` + 文件 | 读取文本、代码、RTF 或 PDF 文字 | 完全本地 |
| `filesum` + 文件 | 读取并总结文件 | 本地 + 云端 AI |
| `find 合同` | 在常用目录中搜索文件名 | 完全本地 |
| `new notes.md` | 在下载目录创建空文件 | 完全本地 |
| `diagnose` | 分析当前系统状态和卡顿原因 | 本地 + 云端 AI |
| `ask 为什么天空是蓝色的？` | 开始一次可继续追问的对话 | 云端 AI |

输入命令时，Briskill 会实时推荐匹配的技能并提示下一个参数。文件和图片可以从 Finder 拖入，也可以通过文件选择器添加。

## 本地工具与 AI 如何配合

Briskill 不会把所有操作都交给大模型。

- **本地任务**直接使用 macOS 系统能力，例如 OCR、文件搜索和剪贴板历史。
- **AI 任务**只在翻译、总结、解释或问答等确实需要语言模型时调用用户选择的服务。
- **混合任务**先在本机读取必要内容，再把界面明确说明的数据发送给 AI，最后继续执行本地步骤。

当前支持配置 DeepSeek、Google Gemini、OpenAI 和智谱 GLM。API Key 由用户自行提供，默认保存在 macOS 钥匙串中。

## 隐私与安全

- 剪贴板历史、技能和调用记录默认保存在本机
- API Key 默认使用 macOS 钥匙串保存
- 剪贴板完整归档可以选择 AES-256-GCM 加密
- 修改文件或执行高风险自动化前显示确认
- 工具日志记录步骤、字段和耗时，不记录剪贴板原文或模型回答正文
- 云端技能会展示将发送的数据和目标服务商
- 无法执行的工具会明确报错，不会伪装成已经完成

部分功能需要 macOS 辅助功能、屏幕录制或用户选择的文件夹权限。Briskill 只在对应功能需要时请求权限。

## 开始体验

### 系统要求

- macOS 15 或更高版本
- 当前主要面向 Apple Silicon Mac 开发和验证
- Xcode 27 开发环境
- 如需使用 AI 功能，需要至少配置一个支持的服务商 API Key

### 从源码运行

1. 克隆本仓库。
2. 使用 Xcode 打开 `Briskill.xcodeproj`。
3. 选择 `Briskill` Scheme 并运行。
4. 从菜单栏打开设置，配置需要的 AI 服务。
5. 按 <kbd>⌥</kbd> + <kbd>Space</kbd> 打开主面板。

不配置 API Key 也可以使用 OCR、文件搜索、文件读取、剪贴板历史等本地功能。

## 当前状态

已经可以体验的核心能力包括快捷主面板、14 个可编辑内置技能、个人技能创建、Skill Runtime V3、连续问答、剪贴板历史、本地 OCR、文件工具、系统诊断、中英文界面和更新检查。

仍在开发的主要能力：

- Spotlight App Intents 和 Core Spotlight 技能索引
- 本地小模型与自然语言工具路由
- 剪贴板语义搜索、收藏和敏感内容识别
- 技能包导入、签名和版本历史
- 通用网络请求、通知和原生多模态文件通道
- 更完整的自动化测试、撤销和持久化审计

Windows 原生客户端仍在独立开发和真实 Windows 11 验证阶段，目前不包含在仓库发布内容中。
